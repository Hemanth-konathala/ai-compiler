# AI Compiler

AI Compiler converts natural language prompts into software architecture, schemas, runtime simulation and generated code.

## Features

- Intent Extraction
- System Design
- Schema Generation
- Validation
- Repair Engine
- Runtime Simulation
- Code Generation
- Architecture Diagram
- Project Export (.zip)

## Example Prompt

```text
Build CRM with login dashboard payments analytics
```

Generated:

- Login Page
- Dashboard
- Payment System
- Analytics
- API Schema
- Database Schema
- Runtime Simulation

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Python
- FastAPI

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run backend:

```bash
uvicorn main:app --reload
```

Open:

```text
frontend/index.html
```
